# 示例：把一份共创 brief 拆成可执行清单

> 这是"解析 brief"这一步的产物样式，不是模板文案。指标一律以你手上的 brief 为准。

## 一、基础信息

- 事件：某车型正式上市发布会（11/12）
- 平台：**抖音、视频号**（只此两个；小红书/B站不计分）
- 窗口：11/12–11/14（今天 11/14，最后一天）
- 回传：11/15–11/17，问卷 `https://example.wjx.cn/vm/xxxx.aspx`

## 二、硬指标

| 项 | 要求 | 计划 |
|---|---|---|
| 时长 | > 15s | 35.5s |
| 文案 | > 15 字 | 140+ 字 |
| 口播 | 必须有（可 AI 配音） | 云扬男声全程口播 |
| 封面 | 需有标题、字完整 | 1080×1440 定制封面 |
| 二创 | 禁一键成片/搬运 | 18 镜重剪 + 调色 + 字卡 + 音效 |
| 植入话术 | 「科技豪华成就宽适人生」 | 标题+简介+口播+尾卡各一次 |

## 三、话题

- 必带：`#品牌车型上市`
- 其他：`#品牌车型宽适人生`、`#品牌车型上市价26.99万元起`
- 注意：部分活动要求"六选二"，多带可能判无效 → 按 brief 原文来

## 四、素材结论

- 官方 TVC 为 2.39:1 遮幅 → **不用**（竖屏只剩 24% 有效宽度）
- 主素材：产品空镜（1080p）、内饰片（2560×1440）、4K 细节空镜
- 素材音轨检测：多为静音或环境噪声 → 全部走 BGM，不用原声

## 五、镜头分配（35.5s / 18 镜）

| 时间 | 台词 | 镜头 |
|---|---|---|
| 0–3.7 | 价格钩子 | 氛围灯座舱 → 车身全景 + 大字 |
| 3.7–6.9 | 六边形战士 | 灯组细节 ×2 |
| 6.9–12.9 | 内饰 | 水晶旋钮 / 真木 / 整舱 |
| 12.9–18.3 | 屏幕与 AI | 巨幕屏 / 天际屏 |
| 18.3–24.9 | 空间座椅 | 后排 / 前排 / 躺平 |
| 24.9–30.7 | 性能续航 | 转台 / 灯秀 / 尾灯 + 数据字卡 |
| 30.7–35.5 | 落点 | 车身落版 → 价格尾卡 |

## 六、发布配置

- 抖音标题：`26.99万起！<车型>上市，科技豪华成就宽适人生`（≤30 字）
- 视频号短标题：**不放价格**（`sau` 会吃掉小数点）→ `N8上市豪华一步到位`
- 封面：3:4，大字价格 + 车型 + 一句价值主张
